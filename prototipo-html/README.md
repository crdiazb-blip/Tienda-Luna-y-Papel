# Luna y Papel

Proyecto frontend académico de una tienda de artículos de escritorio. Utiliza HTML5, CSS y JavaScript básico.

## Archivos principales

- `index.html`: inicio de la tienda.
- `productos.html`: catálogo de productos.
- `pedido.html`: formulario de pedido.
- `css/estilos.css`: diseño externo.
- `js/script.js`: validaciones y cálculo del total.
- `imagenes/`: fotografías utilizadas.

## Cómo ejecutarlo con XAMPP

1. Copiar la carpeta `tienda-luna-y-papel` dentro de `C:\xampp\htdocs`.
2. Iniciar Apache en XAMPP.
3. Abrir `http://localhost/tienda-luna-y-papel/`.

El formulario es una demostración académica. No cobra ni guarda información.
